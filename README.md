# Invoice & Act Generator

Статичний браузерний генератор рахунків і актів без бекенду та без вбудованих користувацьких реквізитів.

## Принцип роботи

- усі поля при відкритті порожні;
- введені дані зберігаються тільки в оперативній пам’яті поточної вкладки;
- застосунок не використовує `localStorage`, `sessionStorage`, cookies або IndexedDB для користувацьких даних;
- після оновлення або закриття сторінки введені дані та сесійні пресети зникають;
- конфігурацію можна явно експортувати у JSON і пізніше імпортувати назад;
- генерація DOCX та PDF виконується в браузері;
- у репозиторії немає реквізитів конкретного ФОП, компанії або договору.

## Можливості

- реквізити виконавця та замовника;
- дані договору;
- номер, дата та період документа;
- одна або декілька позицій послуг;
- автоматичний підрахунок суми;
- сума словами українською;
- UAH, EUR, USD та PLN;
- live preview рахунку та акта;
- вибір: рахунок, акт або обидва документи;
- DOCX за замовчуванням;
- PDF;
- сесійні пресети;
- імпорт та експорт повного стану у JSON;
- налаштовувані імена файлів через `{number}`.

## Залежності

Бібліотеки завантажуються з jsDelivr:

- `docx` для DOCX;
- `pdfmake` та вбудований Roboto для PDF з коректною українською кирилицею.

Введені у форму дані не передаються цим бібліотекам через мережу: документ формується локально у браузері.

## Запуск

Застосунок не потребує збірки. Достатньо відкрити `index.html` або опублікувати корінь репозиторію через GitHub Pages.

## JSON

Експортований файл містить поточні поля форми, налаштування генерації, позиції послуг та створені в цій вкладці пресети. JSON створюється тільки після натискання користувачем кнопки експорту.
